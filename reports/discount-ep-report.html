Rule under test

README business rules 1–3 / swagger POST /checkout:

  • cash → 10% discount on the cart subtotal
  • credit_card → no discount
  • paymentMethod must be exactly cash or credit_card; anything else returns 400 (swagger: enum: [cash, credit_card], required)

Technique: Equivalence Partitioning only. Inputs are paymentMethod and the cart subtotal the discount applies to. One value is drawn at random from inside each partition; cart contents are also random, built from the README products (Wireless Mouse 25.00, Mechanical Keyboard 80.00, USB-C Monitor 200.00) and users (alice, bob, carol). Expected values are computed from the rule, not read back from the API.
